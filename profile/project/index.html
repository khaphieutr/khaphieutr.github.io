  • Anomaly Detection (graduation thesis)

    Reproduced "Future Frame Prediction for Anomaly Detection - A New Baseline" (CVPR 2018).

    Role: Researcher

    • Implemented a U-Net based generator trained adversarially (GAN) to predict the next video frame from preceding frames.
    • Enforced spatial (intensity and gradient) constraints alongside a motion (temporal) constraint by aligning optical flow between predicted and ground-truth frames, using the divergence between prediction and reality as the anomaly signal.
    • Trained and evaluated the model on a toy dataset and public benchmarks, using per-frame PSNR between predicted and real frames as the anomaly score.
    • Built a Flask-based demo application to visualize real-time anomaly detection results on video streams.

    PythonTensorFlowGANOptical FlowComputer VisionFlask
